# 记忆曲线 · 高中必修一/二知识点复习助手

一个帮助高中生安排主科复习计划的小工具。

它把高中必修一、二的知识点做成“问题—答案”卡片，再根据你的记忆情况，用间隔重复算法自动安排下一次复习时间。你不需要自己计算哪天该复习，程序会把今天需要复习的卡片整理好。

## 一、主要功能

- 预置 150 张高中必修一、二知识点卡片；
- 覆盖语文、数学、英语、物理、化学、生物、政治、历史、地理；
- 自动生成今日复习队列；
- 支持设置每日新卡上限和每日复习上限；
- 显示问题后再查看答案；
- 选择“忘记 / 模糊 / 记住”；
- 自动计算下一次复习日期；
- 新增、编辑、删除和筛选卡片；
- 查看总卡片数、今日待复习、已掌握和正确率；
- 查看各科卡片分布和未来 7 天复习计划；
- 支持深色模式；
- 支持启动提醒、每日定时提醒和手机日历提醒；
- 每天完成学习任务可以“续火花”，连续学习天数会在顶部显示；
- 支持一键清理学习缓存；
- 支持清除全部用户数据，恢复第一次使用时的状态。

## 二、运行环境

- Windows 7 及以上系统；
- Python 3.8 及以上；
- 使用 Python 自带的 tkinter，不需要安装第三方库；
- 不需要联网。

## 三、运行方式

### 方式一：Windows 一键启动

双击 `启动.bat`。

### 方式二：命令行启动

在当前目录打开命令行，执行：

```bash
python main.py
```

## 五、怎么使用

1. 打开程序；
2. 进入“今日复习”；
3. 先看问题，自己回忆答案；
4. 点击“显示答案”；
5. 根据实际情况选择“忘记”“模糊”或“记住”；
6. 程序会自动安排下一次复习时间；
7. 如果想自己添加知识点，进入“卡片管理”，点击“新增卡片”。

## 六、间隔重复规则

- 忘记：1 天后再复习；
- 模糊：复习间隔变为上一次的 1.6 倍；
- 记住：复习间隔变为上一次的 2.2 倍；
- 最长间隔 180 天；
- 间隔达到 30 天，会统计为“已掌握”。

## 七、火花与续火花

“火花”表示连续学习的天数。

- 每天完成至少一张卡片，就算“续火花”；
- 连续每天完成，火花天数增加；
- 中断一天，下次完成后火花从 1 开始；
- 顶部统计栏会显示当前火花天数。

## 八、学习提醒

在“设置”页可以：

- 开启“启动时提醒我”：打开程序时提示今天还有多少张卡片；
- 开启“每天定时提醒”：程序运行到设定时间时提醒；
- 设置提醒时间：18:00 / 19:00 / 20:00 / 21:00；
- 勾选“使用 Windows 系统通知”：Windows 10/11 通过通知中心弹出提醒；
- 勾选“Win7 兼容模式”：强制使用系统消息框 + 提示音；
- 点击“测试系统通知”：先检查电脑能否正常弹出通知；
- 点击“导出手机日历提醒”，生成 `.ics` 文件。

Windows 7 会自动使用兼容模式，不需要额外设置。如果 Windows 10/11 的 Toast 通知失败，程序也会自动退回系统消息框。

### 程序关闭后也能提醒

在“设置”页可以：

- 点击“创建定时提醒”：在 Windows 任务计划程序中创建一个每天运行的提醒任务；
- 点击“删除定时提醒”：删除这个任务；
- 状态栏会显示“已创建”或“未创建”。

创建后，即使主程序没有打开，Windows 也会在设定时间运行 `reminder.py`。  
`reminder.py` 会读取你的学习进度，如果今天还有待复习卡片，就弹出 Windows 系统通知。

把 `cache/记忆曲线提醒.ics` 导入手机日历后，也可以设置每天闹钟提醒。

## 九、每日学习量

在“设置”页可以调整：

- 每日新卡上限：10 / 20 / 30 / 50 张；
- 每日复习上限：30 / 50 / 100 / 不限。

程序会优先安排已经到期的复习卡，再安排新卡。默认设置为每日新卡 20 张、每日复习 100 张。

每日学习量没有一个适合所有人的固定数字，可以根据自己的时间和错误率调整。一般建议：

- 新卡从每天 10 到 20 张开始；
- 复习时间控制在 30 到 60 分钟；
- 如果错误率很高，先减少新卡，把复习卡完成。

## 十、算法依据

本软件主要参考：

- 艾宾浩斯遗忘曲线：遗忘先快后慢，复习要安排在快要忘记的时候；
- 间隔效应和分散练习：把学习分散到多天，比集中学习更有利于长期记忆；
- 提取练习和测试效应：先回忆再查看答案，比单纯重复阅读更有效；
- Leitner 系统：答对延长间隔，答错回到短间隔；
- SuperMemo SM-2：根据回忆质量调整后续复习间隔；
- FSRS：更现代的间隔重复算法，考虑记忆稳定性、题目难度和目标保留率。

本软件使用的是适合高中阶段理解和修改的简化版本。

## 十一、数据存储

程序把原始题库和你的学习记录分开保存：

- `data.json`：原始题库，不会记录你的使用痕迹；
- `cache/user_data.json`：你的学习记录；
- `cache/settings.json`：你的设置，例如深色模式、每日学习量、提醒时间；
- `cache/daily_stats.json`：今日已完成的新卡和复习数量；
- `cache/spark.json`：火花：连续学习天数和最近学习日期。

如果 `cache/user_data.json` 不存在，程序会自动从 `data.json` 生成一份全新的学习数据。

这样设计的好处是：你想重新开始复习时，只需要清理缓存，不需要重新安装或手动改文件。

## 十二、深色模式

在“设置”页打开“深色模式”后，界面会切换为暗色配色，适合夜间学习，也能减少屏幕光线刺激。

深色模式设置会保存在 `cache/settings.json` 中。

## 十三、清理学习缓存与清除用户数据

### 清理学习缓存

在“设置”页点击“清理学习缓存”后：

- 程序会删除 `cache/user_data.json`、`cache/daily_stats.json` 和 `cache/spark.json`；
- 学习进度和火花会重置；
- 深色模式、每日学习量、提醒时间等设置会保留。

### 清除用户数据

在“设置”页点击“清除用户数据”后：

- 学习记录、今日进度、火花全部删除；
- 深色模式、每日学习量、提醒时间等设置也会删除；
- 导出的手机日历文件会被删除；
- 程序恢复到第一次使用时的状态。

如果要把电脑借给同学，或者想完全重新开始，使用“清除用户数据”。

## 十四、常见问题

### 1. 双击 `启动.bat` 没有反应？

请确认电脑已经安装 Python，并且安装时勾选了“Add Python to PATH”。

### 2. 提示 `No module named tkinter`？

说明当前 Python 没有安装 tkinter。可以重新安装 Python，并勾选 tkinter 组件。

### 3. 我的学习记录存在哪里？

存在 `cache/user_data.json`。复制整个文件夹，就可以把程序和学习记录一起带走。

### 4. 清理缓存会删除我的设置吗？

不会。清理缓存只删除学习记录，深色模式等设置会保留。

### 5. 我可以添加自己的知识点吗？

可以。在“卡片管理”里点击“新增卡片”，填写科目、教材、章节、问题和答案即可。
